# 第三方组件与许可

本仓库的自写代码（`server.js`、`public/`、`tools/`、脚本与文档）采用 [MIT](../LICENSE)。
但程序能干活靠的是一组第三方组件，**它们各自带着自己的许可证**，这里逐一说清楚。

## 总览

| 组件 | 版本 | 用途 | 许可证 | 是否进 git |
|---|---|---|---|---|
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | 2026.10.26 | 解析与下载的核心 | [Unlicense](https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE)（公有领域） | 否 |
| [bgutil-ytdlp-pot-provider](https://github.com/Brainicism/bgutil-ytdlp-pot-provider) | pip 插件 2.0.2 / 服务端 2.0.0 | 本地生成 PO Token，躲开 403 | **GPL-3.0-only** | 否 |
| [FFmpeg](https://ffmpeg.org/) | 7.1 essentials（gyan.dev 构建） | 音视频合并、转码、封面转换 | **GPL-3.0-or-later**（该构建开了 `--enable-gpl --enable-version3`） | 否 |
| [Node.js](https://nodejs.org/) | v24.21.0 | 运行 `server.js` 与 pot-server | MIT | 否 |
| [CPython](https://www.python.org/) | 3.13.14 | 运行 pip 版 yt-dlp | PSF-2.0 | 否 |
| [pip](https://pip.pypa.io/) | 26.1.2 | 升级 yt-dlp | MIT | 否 |

**为什么都不进 git**：它们加起来约 298 MB / 一万多个文件，全部是二进制或可直接安装的包。
版本库只放源码，第三方组件由 `scripts/install-deps.ps1` 从官方渠道拉取，
或者由 Release 里的便携包提供（zip 也不进 git）。

## 各组件的具体来源

### FFmpeg 7.1（gyan.dev essentials build，GPLv3）

`bin/ffmpeg.exe` 取自 <https://www.gyan.dev/ffmpeg/builds/> 的 `ffmpeg-release-essentials`
。该构建启用了 `--enable-gpl --enable-version3`，因此**整体以 GPLv3 分发**。

ffmpeg 官方源码：<https://ffmpeg.org/download.html>（对应 7.1 版本的 tarball 在
`sources/` 目录下）。gyan.dev 的构建页也提供了构建脚本与源码链接。

> 我们只把 ffmpeg 当**独立进程**调用（`spawn` 传参），不与本项目代码链接、不修改它，
> 因此本项目的 MIT 代码不构成 GPL 衍生作品；GPLv3 的传染性仅作用于 ffmpeg 二进制本身。

### bgutil-ytdlp-pot-provider（GPL-3.0-only）

两个部分：

- **pip 插件** `bgutil_ytdlp_pot_provider` 2.0.2 —— 装进 `runtime/python/Lib/site-packages`，
  作为 yt-dlp 的插件被加载
- **服务端** `runtime/pot-server` —— 版本 2.0.0，`package.json` 声明 `"license": "GPL-3.0-only"`，
  实际运行的是 `build/` 下编译好的 JS（上游 v2 仓库不发布 `src/`，源头在开发者自己的构建流程里）

源码与许可证：<https://github.com/Brainicism/bgutil-ytdlp-pot-provider>

同样以**独立进程**方式使用（`node build/generate_once.js` 或 `node build/main.js`），
与本项目代码没有链接关系。

### yt-dlp（Unlicense）

公有领域，几乎没有任何使用限制。以 `python.exe -m yt_dlp` 的方式调用。

### Node.js（MIT）

便携包里的 `runtime/node` 是官方 Windows x64 发行版的精简拷贝。官方发行版内附完整
`LICENSE`（含 MIT 正文及 OpenSSL、V8、npm 等子组件的许可说明），请注意便携包出于体积
考虑可能没有包含它——需要全文时从 <https://nodejs.org/en/about/previous-releases> 下载同名版本即可。

### CPython 3.13.14（PSF-2.0）

`runtime/python` 下有完整的 `LICENSE.txt`。PSF 许可证允许再分发，要求保留版权声明与许可文本。

### pip（MIT）

`runtime/python/Lib/site-packages/pip-26.1.2.dist-info/licenses/` 下有 `LICENSE.txt` 与
`AUTHORS.txt`。pip 还内嵌了一批 vendor 库（各自的许可证在 `pip/_vendor/*/LICENSE*`）。

## 分发便携包时的注意事项

Release 附件里的 zip 包含上述 GPL 组件，**分发二进制时的义务必须履行**（GPLv3 §4–§6）：

1. **附上许可证文本**。建议在 zip 根目录放一份 `第三方组件与许可.txt`，
   内容至少包含本文件的核心表格 + GPLv3 全文链接。
2. **说明源码获取方式**。在 Release 说明里写一句：
   > Bundled FFmpeg 7.1 and bgutil-ytdlp-pot-provider are licensed under GPLv3.
   > Corresponding source: https://ffmpeg.org/download.html ,
   > https://github.com/Brainicism/bgutil-ytdlp-pot-provider
3. **不要声称整个包是 MIT**。README 和 LICENSE 已经写明 MIT 只覆盖自写代码。
4. **不要修改 ffmpeg / pot-server 的二进制**，否则 GPL 要求你公开修改后的源码。

`scripts/package-portable.ps1` 会自动把本文件复制进 zip 的 `docs/` 下，第 1 条的
“附上许可证文本”开箱即满足。

## 我们没用到的

为避免误解，明确一下边界：

- 本程序**不内置**任何下载任务、订阅源或加速服务
- 不包含 DRM 解密、付费墙绕过、会员内容获取相关的任何代码或组件
- 前端不使用任何 CDN、Web Font 或第三方 JS 库（样式与脚本全部内联在 `public/index.html`）
- 后端不使用任何 npm 包（只用 Node 内置模块：`http`、`https`、`fs`、`path`、`child_process`、`net`、`tls`、`zlib` 等）
